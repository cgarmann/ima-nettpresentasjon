# Intelligent Mønsteranalyse (IMA) - nettpresentasjon

Dette er en statisk, klikkbar nettpresentasjon av IMA. Den krever ingen backend og kan åpnes direkte i nettleser.

## Bruk i møte

Åpne:

```text
index.html
```

Presentasjonen er laget for at du kan vise:

- at IMA er egenutviklet
- at bakgrunnen er erfaring fra helse- og omsorgssektoren
- at hovedmålet er bedre og mer forutsigbar hverdag for beboeren
- at bedre oversikt for ansatte og ledere er en bonus
- en enkel klikkbar demonstrasjon av ABC/mønsteranalyse

## Publisering

Fordi siden er ren HTML/CSS/JavaScript, kan den publiseres på for eksempel:

- GitHub Pages
- Vercel
- Netlify

Publiser hele `ima-nettpresentasjon`-mappen, med `index.html` som startside.

Planlagt domene:

```text
ima.schjoldr.io
```
